    Settings

    Google Drive

    1
    Give zcord a Google key

    One-time setup in Google Cloud, about 5 minutes. Sign in there with the same Gmail you'll upload to.

    1. Turn on Google Drive for a new project. Click Open, create a project (name it "zcord") if asked, then click Enable.
    2. Set up the sign-in screen. Click Get started, app name "zcord", your Gmail as support email, audience External, your Gmail as contact, then Create.
    3. Add yourself as a tester. Under Test users click Add users, enter your Gmail, and Save.
    4. Create the key. Application type Desktop app, name "zcord", Create. Copy the Client ID and Client secret into the boxes below right away — Google only shows the secret once (or click Download JSON and import it).

    Other computers

    Use this setup on another computer

    Saves your Google key and class recordings folder into zcord.config.json in the zcord folder. Put that file on your other computer (by committing it to a private GitHub repo, or copying it) and zcord there is ready. Each computer still clicks Sign in with Google once — your sign-in is never saved in the file.

    git add zcord.config.json
git commit -m "Add zcord setup"
git push
